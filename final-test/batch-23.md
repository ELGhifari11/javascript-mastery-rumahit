# 🟩 **HARI 1 — Full Day App Building**

### **TEMA: Membangun 1 Aplikasi/Website/Program yang BERGUNA dan dibutuhkan orang**

Peserta bebas memilih jenis aplikasi, namun **minimal wajib memenuhi fitur berikut**:

## ✅ **REQUIREMENTS WAJIB DALAM APP**

1. **Login** (auth sederhana)
2. **Register**
3. **Manajemen Database via LocalStorage**
4. **Fetch API Public**
5. **Array & Object Manipulation**
6. **CRUD Lengkap (Create, Read, Update, Delete)**
7. **DOM Management** (render list, update, input handling, event handling)
8. **UI Stylish & Modern**
9. **Usefulness** → aplikasi harus berguna untuk manusia
10. **Documentation** (README / Penjelasan Project)

---

## 🧱 **CONTOH IDE APLIKASI**

Peserta bebas membuat aplikasi apapun, contoh:

* To-Do List Premium
* Library Management System
* Absensi Siswa
* Personal Budgeting App
* Habit Tracker
* Recipe Manager
* Notes App
* Mini E-Commerce Catalog
* Jadwal Sholat + API
* Weather App + API
* Health Tracker
* Data Tafsir/Doa App

Asalkan **memenuhi 10 kriteria** di atas.

---

## 📌 **ATURAN PENTING HARI 1**

* Code harus **karya sendiri**, tidak boleh copy paste penuh dari template internet ata AI.
* Boleh melihat dokumentasi, searching bug, mencari inspirasi UI.
* Tidak boleh minta AI membuat full project langsung → tapi boleh bertanya hal-hal kecil.
* Struktur folder harus rapi:

  ```
  index.html
  style.css
  /js
    main.js
    auth.js
    db.js
    ui.js
    ...
  ```

# 🟦 **HARI 2 — Pitchdeck Presentation + Self Recording**

Setiap peserta wajib membuat:

## 🎥 **1. Self Record (Video 3–10 menit)**

Berisi:

* Perkenalan diri
* Project apa yang dibuat
* Fitur yang sudah berhasil diimplementasi
* Kesulitan dan tantangan selama membuat aplikasi
* Insight dan pelajaran berharga selama 1 bulan belajar
* Hal yang disukai dan yang kurang nyaman
* Pesan untuk masa depan dan komitmen setelah kelulusan


Semoga wali/orang tua antum mengetahui perkembangan antum & antum terlatih untuk **Show Up sebagai Programmer**.

---

## 🖼 **2. Pitchdeck / Slide Presentasi**

Format bebas, namun **minimal berisi**:

1. Cover Nama Project
2. Permasalahan (Problem)
3. Solusi (Your App)
4. Fitur-Fitur
5. Tech Stack
6. Demo Screenshots
7. Alur Data (Flow)
8. Tantangan pribadi
9. Insight selama 1 bulan
10. Penutup & Terima kasih

Pitchdeck boleh dibuat dengan:

* Canva
* PowerPoint
* Google Slides

* Copas full project dari internet.
* Menggunakan framework (React/Vue/Svelte/Bootstrap/Tailwind).
