# Final Exam Landing Page

This is a stylish, interactive, and aesthetic landing page for the Final Exam Announcement.

## 🎵 Music Setup
To enable the background music:
1.  Find an energetic/ambitious MP3 file (e.g., "Two Steps From Hell" style or "Lo-Fi Study" depending on preference).
2.  Rename it to `ambition.mp3`.
3.  Place it in the `assets/music/` folder.
    *   Path: `final-test/landing-page/assets/music/ambition.mp3`

## 🚀 How to Run
Simply open `index.html` in your browser.
or use Live Server in VS Code.

## ✨ Features
*   **Enter Overlay**: Ensures music plays (browsers block auto-play without interaction).
*   **Glassmorphism UI**: Modern, premium look.
*   **Scroll Animations**: Elements fade in as you scroll.
*   **Responsive**: Works on mobile and desktop.
